# Pixel Club — mini-jeux

Un petit site d'arcade en français, prêt pour GitHub Pages.

## Jeux inclus
- Snake
- Memory
- Morpion à deux joueurs
- Test de réflexes
- 2048

## Lancer en local
Ouvre simplement `index.html` dans un navigateur.

## Publier sur GitHub Pages
1. Crée un dépôt GitHub (par exemple `pixel-club`).
2. Ajoute `index.html`, `style.css` et `script.js` à la racine du dépôt.
3. Dans le dépôt, ouvre **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Sélectionne la branche `main` et le dossier `/ (root)`, puis enregistre.
6. Après quelques instants, GitHub affichera l'adresse de ton site dans la section Pages.

Aucune installation, aucun serveur et aucune clé API ne sont nécessaires.
